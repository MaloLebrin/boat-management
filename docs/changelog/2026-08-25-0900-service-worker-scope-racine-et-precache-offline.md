# 2026-08-25 — Le service worker s'installe enfin en production : scope `/` et `offline.html` précaché (#482)

Le service worker généré par `vite-plugin-pwa` levait `non-precached-url` à l'évaluation et ne s'installait **jamais** en production : toute la couche hors-ligne documentée (précache, `offline.html`, toast « prête hors-ligne », futur Web Push) était inopérante. Seules la file IndexedDB et l'installation sur écran d'accueil fonctionnaient.

- **Cause 1.** `navigateFallback: '/offline.html'` générait un `createHandlerBoundToURL('/offline.html')` évalué au chargement du SW, mais `offline.html` n'entrait jamais dans le manifeste de précache : le glob Workbox partait du répertoire de sortie Vite (`build/public/assets`) alors que le fichier vit dans `public/`.
- **Cause 2.** Le SW sortait dans `build/public/assets/sw.js` et s'enregistrait à `/assets/sw.js` avec un scope `/assets/` : il n'aurait de toute façon jamais contrôlé une navigation vers `/boats`, `/navigation` ou `/planning`.
- **Correctif** (`vite.config.ts`). `outDir: 'build/public'` (le SW et le runtime `workbox-*.js` sortent à la racine web du build), `buildBase: '/'` (enregistrement à `/sw.js`), `scope: '/'`, et précache explicite de `/offline.html` via `additionalManifestEntries` avec une révision MD5 dérivée du contenu du fichier — les metaFiles ne copient `public/` dans `build/public` qu'après le build Vite, donc le glob ne peut pas le voir. `globIgnores` exclut `sw.js`, `workbox-*.js` et `offline.html` (garde-fou contre un build incrémental).
- **`.gitignore`.** Ajout de `public/sw.js`, `public/sw.js.map`, `public/workbox-*.js{,.map}` pour ne jamais committer d'artefacts si le SW venait à être généré à la racine du checkout.
- **Doc.** `docs/frontend/pwa.md` : nouvelle section « Pourquoi le SW sort à la racine web », tableau d'options complété (`outDir`, `buildBase`, `scope`, précache), alternative `Service-Worker-Allowed` écartée (incompatible CDN).
- **Vérification.** `node ace build` puis Chromium (Playwright) sur le build servi statiquement : enregistrement de `/sw.js` → scope `http://…/`, état `activated`, 162 entrées précachées dont `/offline.html`. Évaluation du SW dans un contexte mocké : plus d'exception, listeners `message`/`install`/`activate`/`fetch` enregistrés. Le test de non-régression automatisé arrive avec #483.
