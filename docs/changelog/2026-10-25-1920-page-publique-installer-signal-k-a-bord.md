# 2026-10-25 — Page publique « Installer Signal K à bord » : kits, deux chemins, HTTPS, FAQ (#1022)

Épopée #986, suite « auto-installation ». La page instruments promettait « Prévois une demi-heure, une seule fois » et renvoyait « Besoin d'aide pour l'installation ? » vers `/help`, qui ne disait rien de Signal K ; le guide `docs/user-guide/instruments-signalk.md` n'était lisible que dans le dépôt. Cette page publique le remplace et devient la cible des liens d'aide (et de l'assistant dans l'onglet, #1023).

- **Routes.** `/fr/installer-signal-k-a-bord` et `/en/install-signal-k-on-board` (`MARKETING_SLUGS.installSignalK`, routes `marketing.{fr,en}.installSignalK`), servies par `MarketingFeaturesController.installSignalK` → page Inertia `marketing/install_signalk`, props `{ locale, content }`. Contenu assemblé par `MarketingInstallSignalKContentService` (types et constantes `*_COUNT` dans `shared/types/marketing_install_signalk.ts`), copie `marketing.installSignalK.*` à plat, EN + FR, tutoiement.
- **Sections.** Hero « Mets ton bateau en ligne toi-même » + bandeau des temps estimés par chemin (`InstallDurationsStrip`) ; « Choisis ton matériel » (`InstallKitsSection`, 3 cartes : Raspberry Pi 4/5 + OpenPlotter + PICAN-M ou Actisense NGT-1 / USB-série NMEA 0183 avec budget indicatif et liens officiels en ancres externes `target="_blank"` ; Victron Cerbo GX → Signal K dans Venus OS Large ; serveur Signal K déjà présent) ; « Choisis ton chemin » (`InstallPathsSection`, plugin recommandé vs appli à bord, comparatif 5 critères : iPhone, écran ouvert, HTTPS, jauges en direct, réseau) ; chemin plugin (`InstallHowToSection#plugin`, 4 étapes : jeton dans l'onglet Instruments, commande `signalkPluginInstallCommand(SITE_URL, null)` rendue dans `BaseCodeBlock`, alternative Appstore avec le paquet `SIGNALK_PLUGIN_PACKAGE`, vérification) ; chemin appli (`InstallHowToSection#app`, 4 étapes : sécurité Signal K, compte lecture seule + jeton, adresse HTTPS, saisie et test) ; HTTPS pas à pas (`InstallHttpsSection` : DuckDNS ou domaine perso, Let's Encrypt par défi DNS-01, `ssl-key.pem`/`ssl-cert.pem` dans `~/.signalk` ou Caddy en frontal, vérification ; repli auto-signé Android/desktop ; iPhone « non validé ») ; « Relie tes moteurs » (`InstrumentsCardsSection` réutilisée : identifiant instruments, heures automatiques, alertes et journal) ; dépannage (`InstallTroubleshootingSection`, 6 lignes : contenu mixte, certificat, non autorisé, injoignable, périmé, historique vide) ; liens croisés instruments / aide / carnet ; FAQ 8 questions ; CTA `/signup?from=install-signalk`.
- **SEO.** `<Head>` comme la page instruments (canonical, hreflang + `x-default`, `og:locale`), JSON-LD `HowTo` à deux `HowToSection` (plugin ; appli + HTTPS) produit par `inertia/utils/install_signalk_schema.ts`, `FAQPage`, `BreadcrumbList` à trois niveaux (home → instruments → guide). Sitemap : priorité 0,7, `monthly`.
- **Maillage.** Menu public « Ressources » (`use_public_nav.ts`, clé `public.nav.installSignalK`) ; carte dans la section Ressources de `/help` (`cards.installSignalK_*`) ; `helpCta` de la page instruments pointe vers le guide au lieu de `/help` ; `faq_a1` / `faq_a6` d'instruments y renvoient ; nouvelle carte partagée `cards.help_*` pour le maillage retour.
- **Garde-fous.** La commande du plugin n'est jamais recopiée dans le JSON (helper partagé) ; les textes ne citent aucun paquet `signalk-*` autre que `SIGNALK_PLUGIN_PACKAGE` (`{package}` interpolé) ; aucune URL externe traduite.
