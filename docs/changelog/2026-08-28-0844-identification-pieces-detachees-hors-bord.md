# 2026-08-28 — Identification des pièces détachées hors-bord (#517)

Parcours guidé « code modèle → vue éclatée → référence » : l'utilisateur qui a une pièce en main sans en connaître le nom part de son moteur enregistré, navigue par ensemble fonctionnel (et non par nom de pièce), repère la pièce sur la vue éclatée du catalogue revendeur et repart avec une référence commandable. Les pièces identifiées s'accumulent dans une liste de réparation exportable. Même architecture que les checklists de diagnostic (#515) : contenu statique i18n-keyed dans `shared/`, persistance légère par moteur.

- **Routes.** `start/routes/spare_parts.ts` : `GET /spare-parts` (index des moteurs éligibles), `GET /boats/:boatId/engines/:engineId/spare-parts` (identification + ensembles), `GET …/spare-parts/assemblies/:assemblySlug` (fiche ensemble), et le panier `POST …/spare-parts/cart`, `PATCH|DELETE …/spare-parts/cart/:itemId`, `GET …/spare-parts/cart/export` (CSV). Auth + `MaintenancePolicy` (view pour les pages, edit pour les mutations).
- **Éligibilité.** `isSparePartsEligibleEngine` (`shared/helpers/spare_parts.ts`) : moteurs hors-bord uniquement. La marque libre du moteur est rattachée au corpus v1 (Yamaha, Johnson/Evinrude, Mercury/Mariner) par `resolveSparePartsBrand`.
- **Contenu.** `shared/constants/spare_parts/spare_parts_content.ts` : 9 ensembles fonctionnels avec intitulé catalogue EN (`CARBURETOR`, `LOWER CASING / WATER PUMP`…), ~40 pièces courantes (nom FR via i18n + intitulé catalogue EN littéral, mention « incluse dans un kit », fourchette de prix indicative sourcée), 5 catégories de pièces sans référence (durite noire automobile, bougie par équivalence NGK/Champion, goupille…), aide plaque signalétique par marque (exemples Yamaha `6E0`/`500552` et Johnson `J50PLEA`), décodage des références Yamaha (5 chiffres centraux = fonction, ex. `14301` = carburateur).
- **Vues éclatées.** Solution v1 de l'issue : liens sortants vers les catalogues revendeurs (Partzilla, Boats.net, Crowley Marine) selon la marque — les contenus des catalogues sont sous droits.
- **Avertissement n° de série.** Alerte systématique sur la page d'identification : un même code modèle couvre parfois plusieurs décennies, le numéro de série départage les variantes.
- **Liste de réparation.** Table `boat_engine_repair_cart_items` (migration `1829000000000`, FK cascade sur `boat_engines`, unique moteur+pièce) : `part_key` stable, quantité (ré-ajout = incrément), référence relevée par l'utilisateur. Export CSV (`;`, BOM UTF-8) avec ensemble, nom FR, intitulé catalogue EN, référence, quantité.
- **Liens avec l'existant.** Fiches de diagnostic (#515) → ensemble de pièces concerné (fiche « essence » → éclaté CARBURETOR…) via `DIAGNOSTIC_SHEET_TO_ASSEMBLY` ; chaque ensemble renvoie inversement vers sa fiche de diagnostic. CTA « Identifier une pièce » dans l'onglet Pièces de la page moteur (hors-bord uniquement). Entrée « Pièces détachées » dans la sidebar (section Maintenance).
- **Frontend.** Pages `inertia/pages/spare_parts/{index,identify,assembly}.vue`, composants `inertia/components/spare_parts/` (identité moteur, grille d'ensembles, liste de pièces, pièces sans référence, liens revendeurs, panneau liste de réparation). Mutations via `router.post/patch/delete` + `preserveScroll`, redirections Inertia côté contrôleur.
- **i18n.** Nouveau namespace `parts.json` (en + fr), clés `flash.spareParts.*` et `nav.spareParts` dans les deux locales. Les intitulés catalogue EN restent littéraux dans le contenu : ce sont des identifiants de recherche, pas de l'UI copy.
- **Tests.** Japa : `tests/functional/spare_parts/` (pages, éligibilité, isolation cross-org, panier — ajout/incrément, clé inconnue, PATCH/DELETE scopés, export CSV, rôles mécanicien et boat_owner). Vitest : `tests/inertia/spare_parts_content.spec.ts` (invariants du contenu, présence des clés i18n dans les deux locales, rendu des composants) + mise à jour de `use_nav_sections.spec.ts`.
- **Hors périmètre (comme l'issue).** Reconnaissance de pièce par photo ; vues éclatées intégrées (partenariat/affiliation ou schémas propres) ; marques hors corpus v1.
