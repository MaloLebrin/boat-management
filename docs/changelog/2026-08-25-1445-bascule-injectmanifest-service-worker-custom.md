# 2026-08-25 — Bascule vite-plugin-pwa en injectManifest + service worker custom (#496)

Le Web Push (#497/#498) exige des gestionnaires `push`/`notificationclick` dans le service worker — impossible avec la stratégie `generateSW`. Bascule en `injectManifest`, stabilisée seule avant d'y greffer les notifications, car elle change plusieurs comportements implicites d'un coup.

- **`inertia/sw.ts`** (nouveau) : `precacheAndRoute(self.__WB_MANIFEST)` + `cleanupOutdatedCaches` ; `self.skipWaiting()` + `clients.claim()` **écrits en natif** (plus injectés par `registerType: 'autoUpdate'`, et sans dépendre de workbox-core) ; NetworkFirst réécrit sur les navigations `/boats|/navigation|/planning` (3 s, 30 entrées, 7 jours, 200 seulement) avec workbox-routing/strategies/expiration/cacheable-response (déjà en devDependencies) ; `NavigationRoute(NetworkOnly)` avec denylist `/api`,`/up` ; repli `offline.html` en `setCatchHandler`.
- **Deux corrections au passage.** (1) Le NetworkFirst est restreint à `request.mode === 'navigate'` : les visites Inertia (XHR `X-Inertia`) répondent du JSON sur les mêmes URLs — l'ancienne règle aurait pu servir du JSON brut à une navigation hors-ligne. (2) Découvert en vérifiant en navigateur réel : `setCatchHandler` ne rattrape que les requêtes **gérées par une route** — sans la `NavigationRoute` par défaut, une page jamais visitée échouait hors-ligne sans repli.
- **`vite.config.ts`.** `strategies: 'injectManifest'`, `srcDir: 'inertia'`/`filename: 'sw.ts'` (bundlé en `sw.js`), `injectManifest.globDirectory` cohérent avec #482, précache explicite d'`offline.html` conservé, `devOptions: { enabled: process.env.NODE_ENV !== 'test', type: 'module' }` pour tester en `pnpm dev` — coupé sous `node ace test` : un SW actif pendant la suite e2e injecte des reloads Vite (optimisation des deps workbox) et du cache de pages qui rendaient `dark_mode.spec.ts` flaky en CI.
- **Garde-fou (#483) adapté.** Le manifeste injecté a un autre format que celui de generateSW (clés JSON, ordre variable) : la détection accepte les deux. 7/7 vérifications vertes sur le build réel.
- **CSP.** `defaultSrc: ["'self'"]` couvre `worker-src` par cascade — reconfirmé, rien à changer.
- **Doc.** Section Service Worker de `docs/frontend/pwa.md` réécrite (options, comportements explicites du SW custom, piège `setCatchHandler`).
- **Vérification.** Build réel + Chromium (Playwright) : SW `activated`, scope `/`, 162 entrées précachées dont `/offline.html`, et **navigation hors-ligne vers une page jamais visitée → `offline.html` servi**. `use_pwa_update.spec.ts` passe sans modification (le contrat `virtual:pwa-register/vue` est inchangé) ; le bundle SSR compile (le module virtuel reste résoluble).
