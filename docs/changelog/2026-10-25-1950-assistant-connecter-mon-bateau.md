# 2026-10-25 — Assistant « Connecter mon bateau » dans l'onglet Instruments (#1023)

Dernière brique de la suite « auto-installation » de l'épopée #986 : un admin Pro sans source voit un parcours pas à pas au lieu de « Aucun instrument connecté » et d'un formulaire adresse/jeton.

- **Étapes.** Matériel à bord (rien / Cerbo GX / serveur Signal K) → chemin (plugin recommandé ou application à bord) → connexion → relier les moteurs → terminé. Stepper vertical, une étape ouverte (`aria-current`).
- **Plugin.** Adresse LAN préremplie selon le matériel (facultative), enregistrement de la source, jeton (`useInstrumentIngestToken`), commande `signalkPluginInstallCommand` dans un `BaseCodeBlock`, repli Appstore. Attente du premier lot : `router.reload({ only: ['instruments'] })` toutes les 10 s, 10 min au plus, puis « Toujours rien ? » avec les causes.
- **Application.** Pré-vol (`probeSignalKServer({ preflight: true })`) qui refuse adresse invalide et contenu mixte sans réseau ; « Enregistrer et tester » ; rechargement complet si l'origine change (drapeau `pendingTest`, la sonde repart au retour) ; résultat : inventaire (version, navire, moteurs, batteries, réservoirs, position) ou erreur traduite avec remède.
- **Moteurs.** Association moteur ↔ `propulsion.<id>` via `PATCH …/engines/:id/instrument-key`.
- **Progression dérivée des données** ; `localStorage` `fleetai:instrument-setup:<boatId>` = `{ hardware, path, dismissed, pendingTest }`. Une source déjà connectée à l'ouverture masque l'assistant (réouvrable). Lecteur : état vide inchangé. Formulaire de source et carte du plugin sous « Paramètres avancés ».
- **Notable.** Sur le chemin plugin sans adresse saisie, la source reçoit `http://signalk.local:3000` (`base_url` est NOT NULL). Le lien vers la page publique d'installation (#1022) passe par `installSignalKPath` (`marketingPath('installSignalK', locale)`).
- **Fichiers.** `inertia/components/boats/show/tabs/instruments/setup/*`, `inertia/composables/use_instrument_setup.ts`, types `InstrumentSetup*` (`shared/types/instruments.ts`), constantes `INSTRUMENT_SETUP_*`, i18n `instruments.setup.*` (EN + FR, vouvoiement).
