# 2026-10-25 — Plugin Signal K `signalk-fleetai` : brief, contrat et test côté FleetAi (#1024)

Épopée instruments (#986), suite « auto-installation » après le script (#1021). Le plugin lui-même vit dans un dépôt séparé, [MaloLebrin/signalk-fleetai](https://github.com/MaloLebrin/signalk-fleetai) (paquet npm `signalk-fleetai`, MIT, TypeScript, Node ≥ 18, Signal K 2.x) ; cette PR pose côté FleetAi ce qui le lie au serveur.

- **Plugin (dépôt séparé, version `0.1.0`).** Lecture seule des deltas `vessels.self` (catalogue FleetAi uniquement) et `vessels.*` (cibles AIS → `ais.<mmsi>`), une valeur par chemin et par fenêtre (`recordedAt` = horloge du serveur au début de fenêtre, SI tel qu'émis), `POST {endpoint}` en `Bearer`, lots ≤ 500, `batchId` uuid, sans `sourceId`. File persistante bornée (1 440 lots) rejouée dans l'ordre, repli exponentiel plafonné à 5 min, `Retry-After` sur `429`, arrêt explicite (`setPluginError`) sur `401`/`403`/`404`/`409`, lot journalisé et abandonné sur `422`. Statuts « Last batch accepted … ago », « Waiting for network (N batches) », « Token rejected ». Vitest + CI GitHub Actions (lint, typecheck, tests Node 18/20/22) et `npm publish` sur tag `v*` (secret `NPM_TOKEN` à renseigner avant la première publication). Vérifié contre le service `signalk` du compose : premier lot en une fenêtre, jeton révoqué → erreur visible sans boucle.
- **Brief.** `docs/architecture/signalk-fleetai-plugin-brief.md` : contrat complet (configuration, abonnements, agrégation, requête, tableau réponse → conduite, file hors-ligne, statuts, garanties de FleetAi, critères d'acceptation).
- **Test de contrat.** `tests/fixtures/signalk_plugin_batch.json` (lot type : moteur, navigation, batteries, solaire, réservoirs, environnement, alarme, cible AIS) relu par `tests/functional/instruments/telemetry_ingest.spec.ts` : forme (uuid, ≤ 500, sans `sourceId`, chemins du catalogue, une valeur par chemin et fenêtre), acceptation entière puis rejeu `ignored`, `last_seen_at` posé, `401 unauthorized` après révocation.
- **Docs.** `docs/domain/instruments.md` (lien dépôt, version minimale, brief), guide utilisateur § plugin (lecture seule, file hors-ligne, statuts dans l'admin Signal K), base de connaissance du copilote (`instruments-signalk` : mention du plugin, mots-clés « signalk-fleetai », « appstore »).
